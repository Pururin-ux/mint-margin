About your inputs

Use amounts and proof counts from one mint, in sats. Group only proofs with the same denomination and the same keyset fee. Enter the keyset’s public input_fee_ppk value and the reserve shown on your Lightning melt quote. The 100-sat example uses sample values.

Cashu sums the fees across selected proofs before rounding up to a whole sat. Mint Margin finds a covering subset with the lowest unrounded mint fee, using the smallest face value and then fewest proofs to break ties. If none covers the quote, it shows the subset with the most value after its mint fee.

The reserve is requested up front. A mint that supports returning change can return the unused amount at settlement. Get a fresh quote if you change the invoice. Coverage is arithmetic and routing can still fail.

Calculations run locally. Enter only amounts, counts, and public fee rates. Keep your tokens, invoices, and wallet credentials in your wallet.
